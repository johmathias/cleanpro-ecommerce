# CleanPro — On-Demand Cleaning Services Platform

A web-based e-commerce platform that connects customers with 
verified cleaning service providers in Tanzania.

## About This Project
This system was developed as a group assignment for the 
E-Commerce Comprehensive Assignment at the Institute of

## Technologies Used
- Frontend: HTML, CSS, Bootstrap 5
- Backend: PHP
- Database: MySQL
- Payment: M-Pesa Daraja API (Sandbox)
- Local Server: XAMPP

## How to Run This Project
1. Install XAMPP from apachefriends.org
2. Start Apache and MySQL in XAMPP Control Panel
3. Open localhost/phpmyadmin
4. Create database by running the file: database.sql
5. Copy the cleanpro folder into C:\xampp\htdocs\
6. Open browser and go to: localhost/cleanpro
